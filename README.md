# Yoga控制中心（YogaITS）

一个驻留在 Windows 系统托盘中的联想笔记本控制中心，集中管理性能、充电、显卡、色彩和音频等设置。功能会根据当前设备及驱动能力自动显示或隐藏。

本实验分支 `experiment/gpu-mode-nvapi` 验证 NVAPI 显示占用保护与分阶段显卡切换事务，正在实机验证；下列既有版本测试记录不代表本次改动已经全部通过。反复插拔显示器后的独显关闭已获实机确认，用户偏好保持及约束解除后的恢复仍待复测，main 与正式发布不受此分支影响。

以下机型均已完成完善测试。除基准机型外，测试重点是验证与 Yoga Pro 16 IPH11 不同的实现路径，而非仅验证表中列出的功能。

| 已完善测试的机型 | 重点验证路径 |
| --- | --- |
| Yoga Pro 16 IPH11 | 基准机型，完整功能及交互验证；5.2 全功能回归、5.3 键盘背光均已实机验证通过。 |
| 小新 Pro 16 IAH7 | 旧版 ITS 服务的性能选项切换。 |
| 小新 Pro 16 IAH10 | 不同屏幕配置下的 ICC 色域切换。 |
| ThinkBook 14 G6+ AHP | TCON 硬件色域控制，P3/sRGB 切换。 |
| ThinkBook 14 G6+ IMH | TCON 硬件色域控制，P3/sRGB 切换。 |
| ThinkBook 14 G7+ IAH | TCON 硬件色域控制，P3/sRGB 切换。 |

其他机型的兼容性仍需实机确认。色彩管理按实际能力自动选择 TCON 或 ICC 路径；TCON 的 Adobe RGB 协议映射已确认，但尚无支持该能力的正样本完成实机验证。

2026-10-19：5.2 优化后的所有功能已在 Yoga Pro 16 IPH11 上完成实机回归并全部通过，包括独显保活的息屏暂停和亮屏恢复。其他已测试机型的记录保留，但不代表已完成本轮 5.2 回归。

2026-10-21：5.3 新增的键盘背光已在 Yoga Pro 16 IPH11 上实机测试通过。采用相同 EnergyDrv 协议的 ThinkBook、小新预期兼容，但该新增功能尚未在这些机型上验收，程序始终按实时能力检测决定是否显示。

## 开始使用

从 [GitHub Releases](https://github.com/wfsg00098/YogaITS/releases/latest) 下载 Windows x64 ZIP；推送主线后会自动构建并发布新版本。

运行环境：Windows 11 x64、.NET 10 Desktop Runtime、兼容的 Windows App Runtime，以及对应的联想硬件驱动和服务。程序需要管理员权限，启动时请允许 UAC 提示。

将已编译的程序完整解压到固定目录，双击 `YogaITS.Tray.exe` 启动。不要只复制 EXE，其他运行文件也需要保留。无需运行联想电脑管家，但不要卸载相关驱动和底层服务。

普通启动会自动打开完整窗口；开启“开机自启”后，登录时只显示托盘图标，不自动弹窗。如果之前已运行其他版本，请先从托盘退出旧版本。

启动时先显示托盘与窗口，再在后台检测设备，功能分组会随检测结果出现。暂时读取失败时会保留已确认的功能并禁用相关操作，恢复读取后自动更新；不会将读取失败直接当作设置已关闭。

主程序默认向 Windows 请求节能显卡，双显卡设备通常使用核显；主程序已有手动显卡偏好不会覆盖。独立的 `YogaITS.dGPUKeepAwake.exe` 设置为高性能显卡偏好，并明确选择 NVIDIA 适配器。首次设置可能在下次启动生效，实际选择由系统和驱动决定。

性能选项按驱动能力兼容新版及旧版联想 ITS 服务，不强制联动 Windows 的电源模式。

## 两种窗口

### 完整窗口：左键点击托盘图标

**左键点击系统托盘图标，弹出完整窗口。** 窗口已打开时，再次左键点击会关闭窗口，但程序继续驻留托盘。

完整窗口包含全部可用功能，可调整大小、滚动浏览。关闭窗口右上角的关闭按钮不会退出程序。

![Yoga控制中心完整窗口](main.png)

### 迷你窗口：右键点击托盘图标

**右键点击系统托盘图标，弹出迷你窗口。** 适合快速调整性能和充电设置、处理独显占用，底部提供“退出”按钮。

点击窗口外部或按 Esc 可关闭迷你窗口；点击“退出”才会结束程序。

![Yoga控制中心迷你窗口](mini.png)

## 功能说明

| 功能分组 | 可以做什么 |
| --- | --- |
| 性能选项 | 切换智能、安静、性能及受支持的极客/创作模式；极客/创作模式在电池供电时不可选择。 |
| 充电设置 | 选择养护、常规、智能快充或夜间优化。夜间优化与其他模式互斥，需要连接电源。 |
| 独显控制 | 结束占用独显的进程、重启独显设备，或开启“保持独显唤醒”以减少部分混合显卡设备的休眠唤醒卡顿。 |
| 显卡工作模式 | 保存集显、双显或智能模式偏好，单独显示实际状态；在电源和显示器等约束下尽量达成偏好。智能模式插电时目标双显，离电时目标集显。 |
| 唤醒和睡眠 | 控制自动唤醒、自动睡眠；开启自动睡眠后可选择速度及受支持的人员辅助判定。 |
| 播放和暂停 | 开启人走暂停、人回播放。 |
| 色彩管理 | 自动使用 TCON 硬件色域或 Yoga 工厂 ICC；按能力显示色域、HDR、ACM，ICC 路径另提供建议亮度和校色文件恢复。 |
| 扬声器降噪 | “仅保留人声”过滤播放内容中的其他声音。 |
| 麦克风降噪 | 选择关闭降噪、单人或多人通话；内置麦克风可按能力提供仅听机主、人声定位。 |
| 声纹管理 | 录制、读取或删除声纹，用于“仅听机主”；录制时可停止并丢弃本次内容。 |
| 键盘背光 | 按 EnergyDrv 实时能力提供关闭、开启或低/高亮度，以及受支持的固件自动档；设置后回读确认。仅完整窗口提供，位于麦克风降噪/声纹管理之后、开盖开机之前。 |
| 开盖开机 | 控制打开笔记本盖子时自动开机，修改后需重启电脑生效。 |
| 杂项 | 开机自启、退出程序；后台自动检查更新，发现新版后仅在完整窗口显示更新卡片，点击并确认后下载、安装及重新启动。 |

## 状态与使用注意

- 灰色边框表示未选中，强调色边框表示已选中。设置等待回读时，原选项和点击项可能同时显示强调色；完成后按实际状态显示，再更新说明。独显操作只在执行期间显示强调色。
- 显卡工作模式的选中项表示保存的用户偏好，下方仅显示实际工作模式。偏好通常保持不变；唯一例外是检测到外接显示器通过独显输出时，集显选项禁用，原有集显偏好自动改为智能并保存。断开后可重新选择集显，已改为智能的偏好不会自动改回。
- 窗口获得焦点时自动刷新，电源、显示器及音频设备变化也会更新对应状态，无需手动刷新。不支持的功能会隐藏，暂时不可用的选项会禁用。
- 实验版显卡工作模式只在联想 WMI 能力探测成功时显示。集显切换以 NVAPI 的实际显示连接状态保护，不依赖 HDMI 白名单；无法确认显示状态时暂不关闭独显。独显外接显示器使用中，额外提示“外接显示器正在通过独显输出。”切换及保活恢复的详细结果保留在“详细信息 / 复制诊断信息”中。
- 已确认进入集显后，NVAPI 不可用不会再误报切换受阻。电源和显示器变化会重新核对偏好并有限次补查；已确认独显可用时显示实际双显，即使联想模式回读仍为集显。明确失败只有限重试，不会无限循环切换。
- HDR 或 ACM 实际开启时，色域切换、亮度联动和在线恢复会隐藏。HDR 按钮只修改启用偏好，尊重 Windows 的电池供电 HDR 设置，界面显示实际状态。
- 只要系统报告 ACM 能力，HDR 开启或关闭、插电或电池供电时都可操作 ACM；ACM 卡片显示系统保存的启用设置，HDR 卡片显示实际 HDR 状态。色域控制始终按实际显示模式判断，实际是否生效由 Windows 决定。
- TCON 路径按屏幕能力显示 P3、sRGB、Adobe RGB，不提供 ICC 亮度联动或在线恢复；不支持的模式不会显示。Yoga ICC 路径保持原有配置名称及亮度功能。
- 插入耳机后，麦克风仅提供关闭降噪和单人通话。仅听机主需要先录制声纹；录制及注册期间不能修改麦克风或扬声器降噪。
- 键盘背光直接读取 EC/固件状态，启动、完整窗口获焦及切换档位时读取，不定时轮询、不保存或自动恢复档位；Fn+Space 与程序作用于同一底层状态，获焦刷新可看到快捷键的修改。四档设备按“关闭、自动、低亮度、高亮度”单行排列；缺少对应能力的设备只显示可用档位。请保留 LenovoFnAndFunctionKeys 正常运行；不接管热键或 OSD。不支持 EnergyDrv 背光协议或读取异常时隐藏整个功能，不提供 ThinkPad 的 IBMPmDrv 后端。
- 结束独显占用进程按 LLT 的批量逻辑排除 `dwm.exe`、`explorer.exe`，并额外保留 `YogaITS.dGPUKeepAwake.exe`；执行前再次核对保护名单、PID 与进程启动时间，身份无法确认或 PID 已复用时跳过。其余占用进程连同子进程一起结束，包括系统和驱动进程，可能丢失未保存内容或影响相关服务。重启独显可能导致屏幕闪烁。使用前请保存工作，外接显示器和其他占用可能阻止独显休眠。
- “保持独显唤醒”仅在大窗口提供，默认关闭，由独立 helper 持有轻量空闲上下文，不锁定频率或强制 P8，实际空闲功耗状态由驱动决定；开启后会增加耗电，并禁用重启独显按钮。偏好会保存；拔掉交流电源时，无论显卡模式如何都会停止 helper，避免增加离电功耗；接通电源且不处于集显模式或睡眠状态时自动恢复。主程序统一处理电源、睡眠与设备事件，并每 10 分钟检查助手及 context、必要时重启助手；helper 不自行决定恢复。主程序正常退出时立即关闭 helper；异常退出后 helper 每 10 分钟检查一次父进程并自行退出。
- 在线恢复会在确认后将本机序列号发送至 Lenovo 校色服务。声纹录制会使用麦克风；停止录制会丢弃本次录音，删除声纹前会再次确认。
- 集显模式下隐藏整个独显控制分组，即使此前已开启保活；开启配置保留、实际保活暂停。切回双显且条件允许后，分组重新显示并恢复保活。
- 息屏时停止保活助手，亮屏后仅在已开启保活、接通交流电源且显卡模式允许时恢复；屏幕仅变暗不会暂停，暂停期间不会清除开启偏好。
- 设置会等待有限时间确认；尚未执行的排队操作超时后取消。已进入硬件调用的操作可能稍后完成，返回后会刷新真实状态，不会为了重试而同时发送多份命令。

## 自动更新

程序启动后在后台检查 GitHub 最新正式版，持续运行时每 24 小时检查一次。发布版本号采用 `x.y-日期时间-提交标识`；仅当远端数字版本不低于当前版本、日期号更新且不是同一源提交时提示更新，不提示降级。发现新版后，仅在完整窗口的“杂项”分组内显示卡片：

```text
新版本可用，点击进行更新
当前版本号 -> 新版本号
```

版本检查和更新包下载均同时请求 GitHub 与 `https://gh-proxy.org/`，采用最先成功且通过校验的结果，并立即停止另一条请求。点击并确认后下载；更新包通过 SHA-256 校验后，程序退出、替换文件并重新启动。更新失败会保留或恢复旧文件，不改动设置、校色缓存及开机自启路径。检查失败不会弹窗或阻塞其他功能。

更新包会检查主程序与两个助手所需文件是否完整。成功更新的暂存及备份保留至少 7 天，之后自动清理；失败或回滚不完整的更新目录不会自动删除。
