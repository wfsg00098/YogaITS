# Yoga控制中心（YogaITS）

驻留在 Windows 系统托盘中的联想笔记本控制中心，集中管理性能、充电、显卡、色彩、音频和键盘背光。功能按设备及驱动能力自动显示或隐藏。

**左键点击托盘图标打开完整窗口，右键点击打开迷你窗口。** 托盘图标位于任务栏时钟旁，可能收纳在隐藏图标区域。

[下载程序](https://github.com/wfsg00098/YogaITS/releases/latest) · [开发与构建](DEVELOPMENT.md) · [反馈问题](https://github.com/wfsg00098/YogaITS/issues)

**非官方工具，按现状提供。** 本项目与联想等厂商无隶属、授权或合作关系；使用涉及硬件和系统设置，操作前请保存工作并阅读[风险与非背书声明](#许可风险与非背书声明)。原版可从本仓库免费获取。

## 下载与运行

当前提供 Windows 11 x64 构建。两个版本具有相同的硬件功能，启动文件均为 `YogaITS.Tray.exe`，请选择一种：

| 下载包 | 界面与依赖 |
| --- | --- |
| `YogaITS-<版本号>-win-x64.zip` | 普通版，原生 WinUI 3 / Mica；需要系统安装 Windows App Runtime。 |
| `YogaITS-<版本号>-lg-win-x64.zip` | 玻璃版，默认使用原生 WinUI 3，可切换液态玻璃；附带所需的 Windows App SDK 运行文件。 |

1. 安装 x64 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。普通版还需要 [Windows App Runtime 2.5.1 x64](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads) 或更新的兼容服务版本。
2. 将选中的 ZIP **完整解压到固定目录**，不要混用两个版本的文件，也不要只复制 EXE。其余助手程序和资源由主程序使用。
3. 双击 `YogaITS.Tray.exe`，允许管理员权限的 UAC 提示。首次启动会打开完整窗口，随后在后台检测设备能力。

无需运行联想电脑管家，但应保留对应的联想驱动与底层服务。切换普通版、玻璃版或安装目录前，先退出已经运行的程序；两版共用配置和单实例，再次启动会调出已运行的实例。

开启“开机自启”后，登录 Windows 时只驻留托盘，不自动弹出窗口。程序会校验计划任务中的路径：移动程序目录后，自启可能显示关闭，重新开启即可创建当前目录的任务。

## 两种窗口

### 完整窗口

**左键点击托盘图标，弹出完整窗口；再次左键点击则关闭窗口。** 关闭右上角的关闭按钮也只关闭窗口，程序继续驻留托盘。

完整窗口包含全部可用功能，可调整大小、滚动浏览。窗口获得焦点时会刷新状态，电源、显示器和音频设备变化也会自动更新对应功能。

![Yoga控制中心完整窗口](main.png)

### 迷你窗口

**右键点击托盘图标，弹出迷你窗口。** 提供性能、充电、结束独显占用进程、重启独显设备和退出，便于快速操作。

点击窗口外部或按 Esc 可关闭迷你窗口；点击“退出”才会结束程序。

![Yoga控制中心迷你窗口](mini.png)

截图展示原生界面，实际选项以当前版本和设备检测结果为准。

## 功能

| 功能分组 | 说明 |
| --- | --- |
| 性能选项 | 切换智能、安静、性能及受支持的极客/创作模式。极客/创作模式在电池供电时保持显示，但不可选择。 |
| 充电设置 | 选择养护、常规、智能快充或夜间优化。夜间优化与其他选项互斥，需要连接电源。 |
| 独显控制 | 结束独显占用进程、重启独显设备，以及保持独显唤醒，减少部分混合显卡机器的独显休眠唤醒卡顿。 |
| 显卡工作模式 | 选择集显、双显或智能偏好，并单独显示实际模式。智能模式插电时目标为双显，离电时目标为集显。 |
| 唤醒和睡眠 | 自动唤醒、自动睡眠；开启自动睡眠后显示速度及受支持的人员辅助判定。 |
| 播放和暂停 | 人走暂停、人回播放。 |
| 色彩管理 | 按能力使用 TCON 硬件色域或工厂 ICC/ICM 配置，提供色域、HDR、ACM，以及 ICC 路径的建议亮度联动和在线恢复。 |
| 扬声器降噪 | 开启“仅保留人声”，过滤播放内容中的其他声音。 |
| 麦克风降噪 | 关闭降噪、单人或多人通话；内置麦克风按能力提供仅听机主、人声定位。 |
| 声纹管理 | 录制、查看或删除用于“仅听机主”的声纹；录制时可停止并丢弃本次内容。 |
| 键盘背光 | 按固件能力显示关闭、开启、低/高亮度和自动档。四档设备按“关闭、自动、低亮度、高亮度”单行排列。 |
| 开盖开机 | 打开笔记本盖子时自动开机，修改后需重启电脑生效。 |
| UI选项 | 仅玻璃版提供，选择原生 WinUI 3 或液态玻璃，以及背景来源。 |
| 杂项 | 按“开机自启、关于、退出”排列；关于展示版本、来源、许可和免责声明。有新版本时，在这三个按钮上方显示更新卡片。 |

### 显卡与独显保活

显卡模式的选中项表示**用户偏好**，说明文字表示**实际模式**。程序在硬件约束下尽量达成偏好；外接显示器通过独显输出时，集显选项禁用，原有集显偏好会改为智能。断开后可以重新选择集显。

“保持独显唤醒”仅在完整窗口提供，默认关闭，开启后会增加空闲耗电。偏好会保存，但离电、息屏、睡眠、集显模式或状态无法确认时暂停；恢复满足条件后继续。集显模式下隐藏独显控制分组，保活偏好仍保留。

结束独显占用进程会连同子进程一起处理，并保护 DWM、Explorer、控制中心及保活助手；其他系统或驱动进程也可能被结束。操作前请保存工作。重启独显设备会先确认，再退出控制中心，由助手处理设备并重新打开程序；可能短暂黑屏或影响外接显示器。

### 色彩与音频

- TCON 按实际能力提供 P3、sRGB、Adobe RGB，不提供 ICC 亮度联动或在线恢复；Adobe RGB 尚待支持该能力的实机验证。
- 工厂 ICC/ICM 模式来自本机实际取得并验证完整的文件。已知模式显示友好名称，未知模式保留完整原始后缀；没有固定模式数量或组合要求。
- HDR 或 ACM 实际开启时，隐藏色域切换、亮度联动和在线恢复。HDR 开关只修改偏好，尊重 Windows 的电池供电 HDR 设置；ACM 按自身能力操作，卡片显示其保存的启用设置。
- 在线恢复需要确认，并向 Lenovo 校色服务发送本机序列号。校色数据损坏时会重试下载；完整性规则和部分文件恢复策略见[开发说明](DEVELOPMENT.md#色彩管理)。
- 耳机麦克风只提供关闭降噪和单人通话。仅听机主需要已录制声纹；录制和注册期间不能操作麦克风、扬声器降噪。
- 键盘背光只读取和设置实际固件状态，不保存档位偏好。Fn+Space 修改后，重新激活窗口即可刷新；请保留 LenovoFnAndFunctionKeys，以使用快捷键和屏幕提示。

## 玻璃界面

玻璃版首次默认使用原生 WinUI 3。在完整窗口的“UI选项”中切换液态玻璃，可选静态图像、桌面壁纸或透明桌面；样式和背景设置会保存。

静态图像会复制到 `%LOCALAPPDATA%\YogaITS\Backgrounds`，之后可移动或删除原图。静态图像和壁纸模式不需要屏幕捕获；透明桌面使用系统捕获能力，可能需要授权。首次准备捕获身份时可能自动重新启动一次；系统限制或授权不可用时，可选择其他背景或原生界面。程序不会自行关闭系统捕获提示，也不会将捕获画面保存为文件。

## 自动更新

启动后会在后台检查 GitHub 最新正式版，持续运行时每 24 小时检查一次。发现符合条件的新版后，仅在完整窗口“杂项”分组出现：

```text
新版本可用，点击进行更新
当前版本号 -> 新版本号
```

点击并确认后，程序下载、校验、替换文件并重新启动。版本检查和下载均同时访问 GitHub 与 `https://gh-proxy.org/`，采用最先通过校验的结果并停止另一条请求，遵循系统代理设置。每条下载都须通过 Release 元数据中的 ZIP SHA-256 校验；新包还会校验包内逐文件清单，安装助手再次检查原包并核对写入文件，校验失败不继续安装。检查失败不会弹窗或阻塞其他功能。

普通版只更新为普通版，玻璃版只更新为玻璃版；不区分界面版本的旧版会选择普通版。若想更换界面版本，请退出程序后手动下载对应 ZIP。更新不会提示降级，也不会改动设置、校色缓存或自启路径；失败时会保留或尝试恢复旧文件。

以下机型已完成完善测试。除基准机型外，重点验证与 Yoga Pro 16 IPH11 不同的实现路径，而非仅测试表中的单项功能。

| 已完善测试的机型 | 重点验证路径 |
| --- | --- |
| Yoga Pro 16 IPH11 | 基准机型，完整功能及交互验证。 |
| 小新 Pro 16 IAH7 | 旧版 ITS 服务的性能选项切换。 |
| 小新 Pro 16 IAH10 | 不同屏幕配置下的 ICC 色域切换。 |
| ThinkBook 14 G6+ AHP | TCON 硬件色域控制，P3/sRGB 切换。 |
| ThinkBook 14 G6+ IMH | TCON 硬件色域控制，P3/sRGB 切换。 |
| ThinkBook 14 G7+ IAH | TCON 硬件色域控制，P3/sRGB 切换。 |

小新 Pro 14 IRH8 另已完成显卡工作模式专项验证，使用普通版电脑管家时仍然有效。其他机型及尚未报告的功能组合需要实机确认；详细版本范围和回归记录见[实机验收](DEVELOPMENT.md#实机验收)。

功能缺失通常表示设备未提供对应能力，或所需驱动、服务当前不可用。暂时读取失败会保留已确认能力并禁用操作，恢复后自动刷新。反馈问题时请提供程序版本、普通版/玻璃版、机型、Windows 版本及复现步骤，勿附完整序列号或私人录音。

## 文件与卸载

两版共享 `%LOCALAPPDATA%\YogaITS` 下的设置、托管背景、校色缓存及更新暂存。更新成功的暂存目录保留至少 7 天后清理；失败或回滚不完整的目录保留，便于恢复。程序不创建 `Logs` 目录。

卸载前关闭“开机自启”，退出程序后删除解压目录即可；已写入的硬件设置和已安装的 ICC 配置不会随删除程序自动还原。需要清除个人设置时再删除上述数据目录。玻璃版的捕获身份清理方法见[开发说明](DEVELOPMENT.md#配置与故障排查)。
